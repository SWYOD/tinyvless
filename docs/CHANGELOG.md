# Changelog

Сводная хронология линейки **Portable** (Cudy LT300 v3.0). Полные технические подробности
каждой версии — в описании соответствующего [GitHub Release](../../releases); здесь — только
однострочная суть каждого шага, чтобы видеть общую траекторию проекта.

Даты — фактические даты сборки/прошивки, не даты публикации в этот репозиторий.

| Версия | Дата | Суть |
|---|---|---|
| v1-GOOD | 2026-07-05 | Первая рабочая база: свой Go VLESS+WS+TLS клиент, REDIRECT(TCP)/TPROXY(UDP), статус-API, LuCI-морда. |
| v2 | 2026-07-05 | Первый заход на перформанс после нагрузочного теста с телефона (диагностика: лимит соединений душил YouTube). |
| v3 | 2026-07-06 | Фаза A (перф): `dialSem` 48→96 блокирующий-с-таймаутом вместо non-blocking-drop, побайтовое WS-маскирование, QUIC `reject` вместо `drop`. Фаза B: морда v3 (мульти-профили `links.json`, попапы add/edit, 3 кнопки режима, прогресс-бар), safety-валидация (Reality/XTLS определяются и блокируются — только WS/TLS), авто-откат битого активного профиля. |
| v6-validation-antioom | 2026-07-07 | Валидация ссылки при добавлении (`-testlink`, one-shot dial+exit-IP). Анти-OOM: `sync.Pool` для буферов/кадров. |
| v7-zapret | 2026-07-07 | Первая попытка интеграции Zapret (nfqws DPI-обход, альтернатива крипто-туннелю для YouTube/Discord) — запечено в образ, выключено по умолчанию. |
| v8-doh | 2026-07-07 | **Найдено и исправлено DNS-отравление провайдера** (Instagram резолвился в `127.0.0.1`) — DoH split-DNS (`https-dns-proxy` + dnsmasq no-resolv, RU-домены на Яндекс DNS, остальное через DoH). Несколько итераций Zapret (RAM/CPU-конфликт с туннелем на 385МГц/58МБ железе) — **финальный вывод: Zapret+туннель одновременно нежизнеспособны на этом железе**, Zapret выключен, инфраструктура оставлена в коде (флаг). LED-индикаторы сигнала (свой демон `tvled`, AT+CSQ). |
| v9-cursor / v9-plus-cursor | 2026-07-09 | Разработка через Cursor: панель микротюнинга, селективный UDP-туннель (домены+Discord-порты вместо всего UDP), карточка DNS-резолва (DOH_MODE off/smart/full, детект отравления), `ru_cidr` geo-набор (агрегация до /16), `dns-watchdog` self-healing демон, IPv6-hardening (закрыта утечка реального IP). |
| v10-magnumopus | 2026-07-09 | Консолидация Cursor-веток. **Zapret вычищен полностью** (код+пакеты+артефакты — эксперимент завершён, вывод v8 закреплён). Дедуп per-MAC bypass. Diff-gated рестарт dnsmasq в микротюнинге. |
| v11-magnumopusplus | 2026-07-13 | QA-driven фиксы: `TINYVLESS_NICE` (была мёртвая настройка), `ru_set` API-вызов забэкграужен (24с блокировки → ~0.1с). Спидтест (тоннель vs напрямую), SMS-страница, бэкап/восстановление конфига, переупорядочивание карточек панели, страница «Для разработчиков». |
| v12-magnumopusplus | 2026-07-24 | **Первый релиз, безопасный для передачи другому человеку.** Починен `atcmd` (AT-команды к модему — карточка «Модем» и SMS-страница не работали из-за отсутствующего в сборке бинаря). LAN IP (192.168.10.1) впервые закреплён через `uci-defaults` (переживает прошивку). WiFi открыт без пароля, root-пароль не задан, VLESS-конфиг пуст — первичная настройка как на vanilla OpenWrt. |
| **v13-magnumopusplus** | 2026-07-26 | Новый демон `net-watchdog` (здоровье сети провайдера — ping+nslookup к настраиваемому домену). `tvled`/`atcmd` делят один AT-порт через `flock` + настраиваемый таймаут (раньше ничего не защищало параллельный доступ к модему). Карточка «Модем»: поля здоровья сети + кнопка ручного обновления LED. Баннер плохой связи (опционально). Страница разработчика: видимость полей карточки «Модем» настраивается. Переднее LED мигает бело-красным при старте poweroff/reboot из панели. |

## Планы (см. README → Roadmap)

- Пересборка v1–v11 с очищенными секретами и публикация как исторических релизов (см. TODO
  в README) — восстановит полную видимую иерархию релизов с v1.
- Линейка **Stationary** (роутер без автономного питания/модема).
- **opkg/apk-пакет** — установка tinyvless поверх существующего OpenWrt без полной прошивки.
